Lost Paradise for Windows
=========================

1. Put your dump of the game (the folder with eboot.bin, e.g. CUSA12776) in the "game" folder
   next to Lost Paradise.exe. Start Lost Paradise.exe once and it makes that folder for you.
   A .pkg can be unpacked from the launcher too: the gear at the bottom right, then Tools.
2. Start Lost Paradise.exe and press Play.

Needs Windows 10 (1803 or later) or Windows 11, and a graphics driver with Vulkan 1.3
(NVIDIA, AMD or Intel; install the latest driver from the vendor).

Saves go in lpn-data, settings in lpn-display.ini, and the game's log in play.log, all in this
folder. The shader cache is in %LOCALAPPDATA%\lpn-host.

If the game does not start, play.log says why.

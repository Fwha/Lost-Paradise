**Non-register dependencies and literal whole-state reads**

- `DrawRegs::of`, R:148, reads `ctx`, primitive, index type, and instance count.
- **All `ctx[0x000…0x3ff]` words are read** by analysis comparison/hash at R:881–885. That hash controls reuse at R:9240,9369. Recorder copies additionally use `ctxSerial` at R:10324–10329. Therefore even unused shader-stage words and uncovered register holes retain a PM4 dependency.
- `indexBase` and `indexBufferSize` have **no direct renderer reads**. The feed draw supplies `DrawCall.indexAddr/count` from the capture at pm4.cpp:347–350. Engine address arithmetic is proven at `eac462–eac479`, using `S+0x688/+0x690`; `indexOffset` stays zero on this path. `indirectBase` is outside this indexed-draw path.
- Vertex input adds **no conventional vertex-input register reads**: translated Vulkan vertex input is empty at R:4084. Native vertex descriptions come from analyzed VS buffers/fetch data at R:5564–5579, ultimately requiring successful engine user-data/table feeding.
- Optional diagnostics read additional shader banks: indexed-draw tracing reads CS PGM at R:1132; GS diagnostics dump register banks at R:1049–1051. These are separate from ordinary material/character rendering semantics.

**Setter timing: calls are synchronous when taken, but are not guaranteed per draw**

`eac430` calls `e574c0` at `eac480`, then reaches the indexed-draw HLE wrapper through `eac498 → fa0a10`. Thus setters executed there run on the command-generating thread before the draw HLE call. **Neither setter is unconditional:**

- **VS:** `G+0x238 & 4` guards emission at `e57536–e5753a`. Selected header is `*(G+0x100)`, previous emitted header `*(G+0x118)`. Set/update sites are `e5759a/e575b2`; thunks identify `sceGnmSetVsShader`/`sceGnmUpdateVsShader`. `e57fc5–e57fce` only marks changed selection dirty.
- **PS:** `G+0x238 & 2` guards normal emission at `e575cf–e575e1`. Selected header is `*(G+0xc0)`, previous emitted header `*(G+0xd8)`. Set/update sites are `e57661/e576d4`. An unchanged non-null PS can bypass both. Null PS emission clears only the subset shown at H:209–212; other words remain inherited.
- **PS input controls:** separate dirty/change tests at `e57b40`, `e57bb0–e57bc5` can skip emission. The setter writes only `P.byte38` words, leaving the remaining register suffix inherited.
- Dirty bits are cleared at `e57bfb–e57c03`.

Consequently, HLE interception must include **set and update calls**, retain effective last-set state associated with **G and command-buffer generation**, and snapshot it for the draw after lazy emission. A thread-local “latest shader” alone cannot distinguish interleaved contexts. Initialization/buffer rollover needs explicit seeding or invalidation.

To satisfy the strict goal, also capture the uncovered setters/defaults, resolve window/generic scissors, eliminate unknown-word/user-data fallback for claimed draws, and replace whole-PM4-context hashing/copying with a fully engine-owned snapshot or a hash of its relevant fields.
